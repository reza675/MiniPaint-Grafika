# MiniPaint Grafika

Aplikasi Mini Paint untuk Tugas Akhir Grafika Komputer dan Multimedia.  
Menyediakan kanvas menggambar interaktif dengan berbagai tool, transformasi, dan animasi.

## Fitur Utama
- Tool menggambar: Line, Bezier, Rectangle, Circle, Triangle, Fill, Text, Select
- Algoritma: DDA/Bresenham (garis), Bezier Curve, Flood Fill
- Kurva: Bezier / B-Spline
- Atribut: warna, ketebalan, style garis
- Transformasi: translasi, rotasi, scaling
- Animasi: bounce, pulse, spin
- Multimedia: teks dan gambar
- Undo, clear canvas, simpan PNG

## Cara Menjalankan
1. Pastikan Python 3 dan Tkinter tersedia.
2. Jalankan aplikasi:
   ```bash
   python main.py
   ```

## Struktur Singkat
- `main.py` — entry point dan GUI utama
- `canvas_manager.py` — manajemen kanvas dan objek
- `drawing_algorithms.py` — algoritma menggambar
- `transform.py` — transformasi objek
- `animation.py` — animasi objek
- `object_model.py` — model objek gambar
